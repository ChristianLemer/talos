# Talos

> Τάλως — the bronze automaton that guards the perimeter, in a loop.

The **graphical promoter and installer** that puts software on a machine,
repairs it, and shows its state — *by showing* what it does. Its inaugural
payload is Tekton itself (Chiron included, as a removable example). See
[INTENTION.md](INTENTION.md).

**Status: nascent.** The scope is set; the surfaces and the anatomy remain to
be designed. We begin with the installer.

The core is generic: it knows no client. Everything specific — theme, packages,
plugins — enters by *extension*, never into the core.
